## 📥 How to Import

To use this badge list in **NuvioMobile**:

1. Copy the raw link to the `badges.json` file in this repository.
2. In `NuvioMobile`, navigate to **Settings ➡️ Streams ➡️ Stream Badges**.
3. Paste the URL and click **Import**.
